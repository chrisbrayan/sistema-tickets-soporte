# Frontend Angular — Sistema de tickets

Frontend del APF3, generado con Angular 21 y configurado para utilizar Tailwind CSS.

## Ejecutar

```powershell
npm ci
npm start
```

La aplicación se sirve normalmente en `http://localhost:4200` y consume el backend en `http://localhost:8080`.

## Verificar compilación

```powershell
npm run build
```
